# BYCS Web Components

This repo contains a collection of interactive web components which can be used to include into a BYCS course. 

> [!WARNING]  
> The components are all written by AI.


## Usage

Open the Code view and add this snippet.

```html
<script src="https://cdn.jsdelivr.net/gh/jomaway/bycs-web-components@latest/components/pwm-simulator.js" defer></script>

<!-- Add as many simulators as you want! -->
<pwm-simulator></pwm-simulator>
```
